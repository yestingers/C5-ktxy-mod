# V0.2 游戏内验收清单

自动测试命令：

```powershell
python Tests\validate_v02.py
```

自动测试覆盖 XML 解析、模组清单、三语言 Tag、DDS 尺寸与透明度、Atlas
引用、单位数值、城市加成，以及读档/新城市/死亡不复活的状态模型。

游戏内仍需按以下步骤验收：

1. 只启用 CIV5MPDLL、Super Power 10.93 与卡提希娅文明 V0.2。
2. 在文明选择界面确认列表可滚动、卡提希娅可选、头像与徽记正常。
3. 建立首都并结束回合，确认只生成一个卡提希娅单位。
4. 确认单位为 30 战斗力、2 移动力、2 视野、0 维护费。
5. 确认首都获得 +5% 科研与 +5% 生产。
6. 建立第二座城市并结束回合，确认新城市也获得两项 5% 加成。
7. 保存并重新读取，确认不会额外生成卡提希娅。
8. 让卡提希娅死亡，保存并重新读取，确认她不会复活。
9. 检查 `Database.log`、`xml.log` 与 `Lua.log` 中没有卡提希娅相关错误。
