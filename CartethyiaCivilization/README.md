# 卡提希娅—启明之国 v1.0

适用于《文明5：美丽新世界》Windows 单人游戏，按 CIV5MPDLL 62 与 Super Power 10FF 验证接口。v1.0完善圆形人物头像、开场、地理地图、独立技能图标与原生音乐，并加入开局赠送和10回合复活；离线测试与游戏内验收状态见下文。

## 文明与英雄

“启明之国”：所有城市科研、文化、生产各 +10%，当前首都各 +20%。

开局即获得唯一卡提希娅，无须先建立首都，新游戏默认为智慧形态。优先在移民所在格生成，军事格位被占时选择附近合法格；生成失败后重试，不重复赠送。两形态始终使用同一个军事单位，共享生命、经验和通用晋升。禁止生产、购买、赠送、解散、常规升级、被俘及编入军团。

阵亡于第T回合，则从T+10的己方回合起在当前首都复活，各游戏速度均等待10回合。满血、智慧形态，按当前时代成长，保留名字、经验、等级和通用晋升；技能冷却在等待中继续流逝。复活当回合不能行动。没有首都或首都格被军事单位占用时顺延，清空该格后在下一己方回合重试。每次阵亡均适用，存读档不重置等待。

## 操作与技能

选中英雄后，左下单位行动区出现三个不同图标：双向环流为切换、光芒书卷为神启、风刃为裁决。悬停查看对应操作；右侧面板显示形态、战力、冷却和禁用原因，右侧文字本身不是按钮。领袖与单位使用本人圆形头像，文明徽章保留在文明和旗帜位置。

- **切换形态**：每回合最多一次，消耗全部剩余行动；攻击或使用技能后不能切换。切换不回血、不刷新攻击与技能冷却。
- **神启敕令**：智慧形态在己方城市，立即完成当前队列首项合法建造，包括单位、建筑、奇观和有限生产项目。不会连锁完成后续队列，也不给技能额外溢出。标准速度冷却20回合，随建造速度缩放。
- **裁决之风**：力量形态打开六方向面板。悬停方向预览连续三格，单击施放；按距离造成目标最大生命70%/60%/50%的直接伤害，可击杀。冷却5回合；只伤害可见、已交战的敌方军事单位，不伤城市本体、平民或友军。按伤害来源记录英雄，不主动增加普通战斗经验或模拟普通战斗事件；原生伤害与死亡回调照常，具体 SP 被动联动待实测。
- 两个技能都消耗剩余行动；战争技能计作本回合攻击，不能和普通攻击、切换连用。可移动后施放，但必须仍有行动。冷却在两形态下都流逝。
- 登船时不能切换或施放技能。Esc或取消按钮退出方向选择。

## 安装与旧档

依赖 CIV5MPDLL 62 或更高版本、Super Power（本轮参照10FF）与BNW。仅启用一个版本的卡提希娅 Mod。退出游戏后安装更新，再从“模组”菜单启用并进入游戏。

验证开局赠送需新开测试局；不要覆盖唯一的旧存档。v0.3已有英雄保留形态、伤势、经验和晋升；更早无形态记录的英雄按力量形态迁移。旧版本已记录赠送但阵亡、无死亡日期的存档，从首次加载v1.0起等待10回合再复活。旧档真实迁移仍需游戏内验证。

音乐使用游戏自带英格兰曲目，开场采用伊丽莎白和平音乐，移除不相关的美国开场旁白。音量遵从游戏音乐设置；没有另加循环播放器，也不随选中单位或切换形态重复触发。发行包不复制原版音频。

本轮使用原有已实测的单人模型与31段动画，两形态暂共用外观，通过面板和晋升区分。第二形态独立外观、专属施法动作、音效与外交场景属于后续美术工作。AI拥有文明和默认辅政被动，尚未编写主动切换与施法策略。

## 测试状态与手动验收

v1.0是本轮用户指定版本号。自动检查执行真实Lua5.1规则与控制器、SP SaveUtils序列化及UI逻辑；游戏对象与事件使用测试替身，数据库检查使用安装版依赖的表结构。23项Python检查、3组Lua和数据库重复加载检查通过，独立审阅无阻断项。神启敕令已由用户复测可正常使用；本轮复活、新画面及音乐仍需真实游戏验收。

请依次检查：

1. 模组选择页圆形头像/短描述/地图完整，开场人物脸无遮挡、音乐能正常停止。新局未建城即只有一名智慧形态英雄。
2. 切换后行动归零，下一回合力量形态为3移动；切回后仍保留生命、经验和通用晋升。
3. 智慧驻城用神启敕令，确认只完成当前一项；换城和读档后冷却不重置。
4. 力量技能六方向预览与命中一致，敌友混排不误伤；城市本体不受技能伤害。
5. 查看相邻敌军战斗预览中的威压、远程防御和受伤战斗表现。
6. 两种形态分别存读档，验证时代成长、城市转手、首都迁移和英雄阵亡后的收益撤销。死亡T回合后，T+9不复活，T+10当前首都生成一名；确认经验/晋升/冷却保留，并测试首都堵格后延迟归来。

开发目录完整离线检查：`python Tests/validate_all.py`。模型报告见 `Tests/MODEL_STYLE_2026-10-17.md`，本轮记录见 `Tests/V1_IMPLEMENTATION_2026-10-17.md`；此前双形态与神启修复见 `Tests/TRAITS_IMPLEMENTATION_2026-10-17.md`。发布包不包含开发测试工具。
